🧭 WPI CS542 – Database Management Systems

This repository contains my coursework projects and assignments for the graduate-level course CS542: Database Management Systems at Worcester Polytechnic Institute. The course explored the design, implementation, and optimization of modern database systems, with an emphasis on relational modeling, SQL, transaction processing, and scalable data management.

Relational databases, SQL programming, schema design, normalization, indexing, transaction management, and database application development.

Database Application Project — developed a database-backed application integrating frontend logic with relational data storage.
Transaction & Concurrency Analysis — explored ACID properties, locking mechanisms, and concurrency control strategies.
